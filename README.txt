LOOPFORGE LUXE — standalone procedural pattern generator
Open index.html in a modern browser with WebGL2 enabled.
No paid APIs, accounts, build tools or internet access are required.
Choose a preset or enter a prompt; prompts are interpreted by local keyword matching.
Export PNG or WebM. WebM export works best in desktop Chrome/Edge.
Video frames sample a mathematically periodic animation with no duplicate endpoint frame.
Browser recording timing can vary; for frame-perfect offline encoding use a dedicated encoder in a future release.
This is a shader-based 2D/2.5D renderer, not arbitrary 3D geometry or generative AI.
